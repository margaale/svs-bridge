    Bridge firmware

    –
    The bridge downloads the firmware straight from GitHub, checks it (ESP32-S3, project svs_bridge, checksum) and restarts into it. It keeps the new version only once it reconnects to the Wi-Fi; otherwise it goes back to the current one by itself.
    Running–Release notesgithub.com/margaale/svs-bridge

    API token

    Home Assistant discovers the bridge on your network by itself. Paste this token when adding it, so it can read the SVS state.
    Regenerating revokes the old token: update it in Home Assistant afterwards.

    Integration

    The custom integration installs through HACS.
